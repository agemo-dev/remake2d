# Drawable and Fillable traits

Le graphisme à l'ecran est essentiel pour toutes applications ; il est donc necessaire
de pouvoir affiché des objet a l'ecran .

---

## Overviews

Dans cette rubrique, nous allons enfin apprendre à dessiner nos types personnalisés
à l'ecran !
Pour cela , nous utiliserons deux traits specifiques du moteur: **Drawable** et **Fillabe** ;
tous deux contenus dans l'en-tête **"remake2d/window.hpp"**.
